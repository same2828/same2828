# Usage

- Get Deezer AUS ARL from [rentry.org/firehawk52](https://rentry.org/firehawk52) telegram channel
- Make sure you are logged in with Spotify
- ADD Spotify playlist to profile
- Go to Favourites tab > Click on Playlist > Select ALL songs individually > Download Selected
- Note: If issues arise, need to find song on Deezer and copy paste Deezer link into Deemix
