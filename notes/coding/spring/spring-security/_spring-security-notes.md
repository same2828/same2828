# OAuth2 - Dan Vega

- [Dan Vega Video](https://www.youtube.com/watch?v=us0VjFiHogo&list=PLZV0a2jwt22s5NCKOwSmHVagoDW8nflaC)
- start.spring.io
  - Dependencies
    - Spring Web
    - OAuth2 Client
- Setting up GitHub OAuth2
  - Settings > Developer Settings > OAuth Apps > Register a new application
  - Will need to generate a "client secret"
  - Add "client-id" and "client-secret" to `application.properties` file
- Refer to [this link](https://spring.io/guides/tutorials/spring-boot-oauth2) for "Authorization Callback URL"
- Setting up Google OAuth2
  - Skipped since billing account is required

```
# Details to register OAuth2 Application
Spring OAuth2 Social Login
http://localhost:8080
http://localhost:8080/login/oauth2/code/github

# Test
http://localhost:8080/secured
```
